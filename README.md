## ✦ Избранные проекты

### 01. Кафе «Белоснежка» (2025–2026) • `Live WIP`
- **Формат:** Ресторанная платформа, доставка и умная корзина (AOV +34%).
- **Роль:** Авторский UX/UI дизайн в Figma + фронтенд/бэкенд с помощью AI-инструментов.
- **Особенности:** Теплая янтарно-обсидиановая палитра, компонентное меню, физика добавления блюд, быстрая конфигурация сетов.

### 02. PPKAS (2024–2025) • `Web3 Ecosystem`
- **Формат:** P2E игровая платформа и децентрализованная экосистема на базе блокчейна Kaspa.
- **Роль:** Архитектура онбординга, геймифицированный дашборд, интеграция некастодиальных кошельков.
- **Команда & Отзывы:** Международная разработка, официальный отзыв от core-команды (Alex Vance).

### 03. Librium (2024) • `EdTech Mobile App`
- **Формат:** Мобильное приложение для адаптивного микрообучения (6 месяцев разработки).
- **Роль:** Полный цикл продуктового дизайна (от CustDev и CJM до дизайн-системы из 80+ компонентов).
- **Метрики:** D1 Retention 48%, Completion Rate +37%, SUS Score 88/100.

### 04. EZ (2023–2024) • `Logistics ERP`
- **Формат:** Высоконагруженная система управления складской логистикой и маршрутизацией.
- **Особенности:** Эргономичный ночной режим для терминалов сбора данных, сокращение ошибок комплектации на 42%.

### 05. Community Design (2023) • `Design System & Education`
- **Формат:** Образовательная платформа и библиотека компонентов для дизайн-сообщества 15,000+ участников.

## ✦ Запуск проекта локально

```bash
# Клонирование репозитория
git clone https://github.com/anyuta228/Portfolio.git

# Переход в директорию
cd Portfolio

# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка продакшен-бандла
npm run build
```
